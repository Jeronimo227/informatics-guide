# Информатика для первокурсника

## Тема: системы счисления

Цель справочника — кратко объяснить основные понятия систем счисления и показать, как переводить числа между ними.

**Автор:** Арсений Соколов

## Список файлов

- glossary.md — основные термины.
- examples.md — разобранные примеры.
- sources.md — использованные источники.
- questions.md — вопросы для самопроверки.

## Как пользоваться справочником

1. Сначала прочитайте термины в `glossary.md`.
2. Затем разберите примеры в `examples.md`.
3. Проверьте себя с помощью `questions.md`.
4. При необходимости откройте источники в `sources.md`.
