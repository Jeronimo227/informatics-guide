# Глоссарий

- **Система счисления** — способ записи чисел с помощью конечного набора символов и правил.
- **Основание системы счисления** — количество различных цифр, используемых в системе.
- **Двоичная система** — система счисления с основанием 2; используются цифры 0 и 1.
- **Восьмеричная система** — система счисления с основанием 8; используются цифры от 0 до 7.
- **Десятичная система** — привычная система счисления с основанием 10.
- **Шестнадцатеричная система** — система счисления с основанием 16; используются цифры 0–9 и буквы A–F.
- **Разряд** — позиция цифры в записи числа.
- **Вес разряда** — множитель, который определяет вклад цифры в значение числа.
- **Перевод числа** — преобразование записи числа из одной системы счисления в другую.
- **Остаток от деления** — число, остающееся после целочисленного деления.
